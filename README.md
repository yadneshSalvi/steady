# STEADY

Makeup guidance that adapts to your hands.

STEADY will help people choose a makeup look, explore application methods suited to their own preferences and tools, and receive guidance while creating the look themselves.

YouCam supplies personalized appearance previews. Adaptive action planning, local tracking, and feedback from actual application are planned application capabilities.

## Status

Project repository initialized for the YouCam API Skin AI & eCommerce VTO Hackathon. Application implementation, deployment, and user validation have not started. Descriptions above are intended capabilities, not claims of a functioning product.

## Local configuration

Copy `.env.example` to `.env` and supply your own credentials when setting up a fresh clone. This workspace already has a local `.env`; never replace it without preserving its values.

All provider credentials belong on the server. Environment files and the local `plans/` directory are excluded from version control. A fresh clone does not include either.

Runtime installation, development, tests, deployment, and judge-access instructions will be added alongside the implementation. No database, storage service, or deployment is provisioned by this initial repository.
